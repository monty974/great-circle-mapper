# Great Circle Calculator

A web application for calculating the shortest path between two points on Earth using the great circle route. The app displays the path on an interactive map and calculates distance and travel time.

![Great Circle Calculator](https://img.shields.io/badge/React-18.2.0-blue) ![Vite](https://img.shields.io/badge/Vite-5.0-646CFF) ![Leaflet](https://img.shields.io/badge/Leaflet-1.9.4-green)

## Features

- **Interactive Map**: Click on the map to set origin and destination points
- **Manual Input**: Enter coordinates manually for precise locations
- **Distance Calculations**: View distances in kilometers, miles, and nautical miles
- **Travel Time**: Calculate travel time based on average speed
- **Initial Bearing**: Display the initial compass direction
- **Great Circle Path**: Visualize the shortest route on the map
- **Responsive Design**: Works on desktop and mobile devices

## Technologies Used

- **React 18**: Modern UI library
- **Vite**: Fast build tool and development server

## Getting Started

### Prerequisites

- Node.js 16+ and npm

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd great-circle-mapper
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

4. Open your browser and navigate to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The built files will be in the `dist` directory.

### Preview Production Build

```bash
npm run preview
```

## Usage

### Setting Points

**Method 1: Click on Map**
- Click anywhere on the map to set the origin point (green marker)
- Click again to set the destination point (red marker)
- The app alternates between setting origin and destination

**Method 2: Manual Entry**
- Enter latitude and longitude values in the input fields
- Optionally, add location names for better identification
- Latitude: -90 to 90 (negative for South)
- Longitude: -180 to 180 (negative for West)

### Calculating

1. Set both origin and destination points
2. Adjust the average speed (default: 900 km/h for aircraft)
3. Click "Calculate Great Circle"
4. View results and path on the map

### Example Coordinates

- New York: 40.7128, -74.0060
- London: 51.5074, -0.1278
- Tokyo: 35.6762, 139.6503
- Sydney: -33.8688, 151.2093

## How It Works

The application uses the **Haversine formula** to calculate the great circle distance between two points on a sphere:

```
a = sin²(Δφ/2) + cos(φ1) × cos(φ2) × sin²(Δλ/2)
c = 2 × atan2(√a, √(1−a))
d = R × c
```

Where:
- φ is latitude
- λ is longitude
- R is Earth's radius (6,371 km)
- d is the distance

The great circle path is generated by calculating intermediate points along the route.
